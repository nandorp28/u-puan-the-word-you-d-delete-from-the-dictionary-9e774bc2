The Word You'd Delete From the Dictionary — one word to erase from the dictionary forever, picked by dueling three candidates against the top 10 winners of the nearest completed same-type bounty under the judge's own five criteria (in priority order). The winner: **irregardless** — the dictionary finally deletes the word that was never a word. Duel record 12W, margin 51; the other candidates were "please" (11W) and "moist" (10W, docked for freshness — the whole field thinks of it first).

## Run it

```sh
node main.ts
```

Writes the winning word to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR` for local runs). Node 22+ stdlib only.
